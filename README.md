# VetCare Clinic

Concept de site pentru o clinică veterinară, cu programare online direct din prima pagină.

## Ce conține

- Formular de programare rapidă în hero (tip animal, dată)
- Pagini pentru servicii, adopții și contact
- Butoane fixe pentru WhatsApp și urgențe
- Design luminos, gândit întâi pentru mobil

## Stack

React · TypeScript · Vite · Tailwind CSS · shadcn/ui · React Router

## Rulare locală

```sh
npm install
npm run dev
```
